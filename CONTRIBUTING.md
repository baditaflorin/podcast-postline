# Contributing

Thanks for helping improve `podcast-postline`.

## Local Workflow

1. Install Go, Node.js, Docker, `gitleaks`, and `lefthook` or use the plain hooks in `.githooks`.
2. Run `make install-hooks`.
3. Run `make fmt`, `make lint`, `make test`, and `make smoke` before pushing.
4. Use Conventional Commits, for example `feat: add upload flow`.

## Pull Requests

Keep pull requests focused on one concern. Include tests or explain why the change is documentation-only.
